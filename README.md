
# PingPlan - AI Study Planner

PingPlan is a Notion-style AI study planner built for students to manage courses, notes, tasks, focus sessions, flashcards, quizzes, study roadmaps, and collaborative study rooms.

## Features

- Firebase Authentication
- Email and Google Login
- AI Study Planner using Gemini
- AI Doubt Solver
- AI Flashcard Generator
- AI Quiz Generator
- Study Roadmap Generator
- Course Workspaces
- Notes and Task Tracking
- Progress Tracking
- Pomodoro Focus Mode
- Study Calendar
- Real-time Study Room
- Firestore Cloud Sync
- Notion-style UI

## Tech Stack

- React
- Vite
- Firebase Authentication
- Cloud Firestore
- Google Gemini API
- JavaScript
- CSS
- Lucide React

## Project Goal

This project helps students organize their learning, generate AI-powered study resources, track progress, and study collaboratively.
